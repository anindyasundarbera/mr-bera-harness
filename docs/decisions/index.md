# Decision Records

One file per decision, under `docs/decisions/`. Each governs the harness itself;
decisions a *consuming* repository makes about its own delivery stay in that
repository.

**The index is generated, and it is not this file.** See
[../DECISIONS_INDEX.md](../DECISIONS_INDEX.md) — regenerated by `harness entries
generate` from the entries themselves. Read that for the list, the status, and what
supersedes what.

**Why this file deliberately repeats nothing.** It used to mirror the list and, for two
records only, their status as well — so it was hand-synced, partially, and could disagree
with the entries it described. That is the failure this repository keeps paying for: a
second copy of a fact drifts from the first, and nothing tests it (`CHG-2026-016`'s
hardcoded header, `CHG-2026-020`'s stale README). A directory index whose job is to be
*findable* should point at the generated index rather than restate it.

Each record carries its own status in its frontmatter, and each record's `Context`,
`Decision`, `Consequences` and `Alternatives rejected` are the authority for that
decision. Open `ADR-2026-NNN-*.md` directly, or read the generated index above.
